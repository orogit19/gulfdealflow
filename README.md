GulfDealFlow
GCC venture capital intelligence platform tracking 300+ startup funding deals across the UAE, Saudi Arabia, Kuwait, Bahrain, Qatar, and Oman.
🔗 Live: gulfdealflow.vercel.app

Stack: React + Vite + Tailwind · FastAPI · Supabase · Vercel
Features: Deal explorer with filters, search & CSV export · Recharts dashboard + GCC deal map · Investor fund cards & timeline modals · Company profile modals
In progress: Automated ingestion pipeline (RSS + Firecrawl + Claude API) · Insights articles · v1.0

Built as a portfolio project by Stavros Gaiganis.
